# Power BI Sales Analytics Dashboard

## Overview
This project focuses on analyzing sales data using Microsoft Power BI to uncover meaningful business insights. The dashboard provides an interactive view of sales performance, order trends, and customer behavior.

## Key Features
- Total Sales and Total Orders tracking
- Average Sales per Order analysis
- Sales trend analysis over time
- Category and regional performance insights
- Interactive filters and slicers
- DAX measures for dynamic calculations

## Tools Used
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Modeling

## Key Metrics
- Total Revenue
- Total Orders
- Average Sales per Order
- Sales Growth Trends
- Top Performing Categories

## Objective
To transform raw sales data into meaningful visual insights that help businesses understand performance and make informed decisions.
